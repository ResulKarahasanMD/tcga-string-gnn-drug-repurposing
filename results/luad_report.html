Stage 02 · GNN gene prioritization

The graph helps — but network propagation still wins

Labels are 31 Open Targets LUAD genes + 31 degree-matched negatives. Two honest results sit side by side:

  • graph is used Real graph AUPRC 0.844 beats degree-rewired 0.723 and features-only 0.659 — topology carries signal.
  • baseline wins Random-walk-with-restart (0.967) out-ranks every GNN (GCN 0.842, GATv2 0.824). Reported, not hidden.
  • edge weights matter GCN/GATv2 > GraphSAGE (0.680), which ignores edge confidence.
  • not a hub story Degree-rank AUPRC 0.49 — high degree ≠ disease gene.
Caveat surfaced by the data. Only 62 labeled nodes → wide CIs (AUPRC 95% [0.55–1.0]). The raw global ranking is dominated by isolated high-variance genes (cancer-testis antigens, mucins) whose scores aren't smoothed — so the disease module uses connected, seed-proximal genes instead.

Two mechanism caveats worth stating. (1) Gefitinib scores 0% direction-consistency because EGFR is only mildly mRNA-up — it's activated by mutation/amplification, not overexpression (mRNA ≠ protein activity). (2) Erlotinib buries at #2397 because DGIdb's approved-target set for it differs from gefitinib's — proximity is sensitive to target-annotation completeness.
Stage 04 · Validation & provenance

Biological and statistical checks

Pathway enrichment

Disease-seed genes' top pathway (against the 16,251-gene analysis background, not the genome): “Non-small cell lung cancer”, KEGG FDR 1.8×10−21.

Bosutinib targets

Verified live via DGIdb: ABL1 + SRC + STE20/SIK off-targets. ABL2 absent despite literature — ABL1 ≠ ABL2 ≠ SRC. LUAD demo rank 31 (FDR 0.46).

Reproducibility

uv + Python 3.12, torch 2.13 / PyG 2.8 on MPS. Seeds fixed; per-run manifests log config, package versions, input SHA-256, timestamp. 57 tests pass.

Deliverable

21 modules, one command

Core logic lives in src/repurpose_gnn/; notebooks and scripts/ are thin layers. The whole chain runs as python -m repurpose_gnn.pipeline --config configs/luad.yaml. Swap the cohort by config; a documented rhabdomyosarcoma / bosutinib adaptation (TARGET / St. Jude, subtype + fusion stratification) ships as a template — with no fabricated RMS result, because TCGA has no RMS cohort.
